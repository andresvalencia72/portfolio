Caso profesional / Sistema utilizado en producción

Software de coordinación de emergencias y recursos

Desarrollé servicios backend y un panel de gestión para apoyar la coordinación operativa de incidencias, estados y recursos.

ÁmbitoOperaciones · Emergencias
Mi responsabilidadBackend y panel Angular
EstadoSistema utilizado en producción

01 / Contexto

El problema que había que resolver

El sistema debía trabajar con avisos externos, permitir localizar recursos, gestionar permisos y mostrar información operativa actualizada a quienes coordinaban incidencias.

02 / Contribución

Qué hice yo

  • Desarrollé lógica backend en NestJS para gestionar incidencias, estados y permisos.
  • Implementé consultas de proximidad y localización utilizando PostGIS.
  • Trabajé en el panel Angular y en la comunicación en tiempo real mediante sockets.
  • Participé en la integración de avisos procedentes del 112.

03 / Ingeniería

Decisiones y desafíos técnicos

  • El tratamiento de datos geoespaciales era relevante para relacionar incidencias y recursos cercanos.
  • Roles y estados debían mantenerse coherentes entre backend y panel de gestión.
  • La comunicación en tiempo real requería coordinar eventos sin presentar información obsoleta.

04 / Evidencia

Qué se puede comprobar

Puedo detallar las responsabilidades técnicas y los criterios empleados, respetando la confidencialidad del sistema. No publico capturas ni código profesional privado.
