PlantOps · Gestión de operaciones industriales

Construyo PlantOps como proyecto de ingeniería: una aplicación para organizar activos, incidencias y órdenes de trabajo entre organizaciones.

ÁmbitoProducto industrial · CMMS
Mi responsabilidadDiseño e implementación full stack
EstadoEn desarrollo · Código público

01 / Contexto

El problema que había que resolver

En un entorno industrial es necesario vincular incidencias a activos, gestionar órdenes de trabajo y controlar las responsabilidades de cada perfil. El proyecto aborda esas reglas de negocio sin perder trazabilidad y aislamiento entre organizaciones.

02 / Contribución

Qué estoy construyendo

  • Definición de casos de uso, reglas de negocio y permisos entre perfiles de usuario.
  • Desarrollo de frontend React y backend NestJS con persistencia PostgreSQL.
  • Trabajo por incrementos revisables con pruebas, ramas y pull requests separados.

03 / Ingeniería

Decisiones y desafíos técnicos

  • Separación de responsabilidades entre aplicación, negocio y persistencia.
  • Modelado de relaciones entre incidencias, activos y órdenes de trabajo.
  • Control de acceso y de datos entre organizaciones.
  • Diseño orientado a pruebas y evolución gradual de funcionalidades.

04 / Evidencia

Qué se puede comprobar

El repositorio público permite consultar el código y su historial. Algunas funcionalidades siguen en revisión y no existe una demostración pública validada del producto completo.
